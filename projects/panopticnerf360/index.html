Abstract

PanopticNeRF-360 renders panoramic 2D panoptic labels from readily available coarse 3D bounding primitives.

Overall Framework

At each 3D location sampled in a 360 scene, we formulate scene feature combining MLPs features and multi-resolution hash encoding features to unify their merits, inductive smoothness and expressive local details. Then we leverage dual semantic fields to obtain two semantic categorical logits. The semantic losses applied to both semantic fields improve 1) the volume density and 2) the 3D semantic predictions. Our method allows for rendering panoptic labels by combining the learned semantic field and a fixed instance field determined by the 3D bounding primitives. To mitigate intersections in the same semantic classes, mainly ''building''', we further perform plane regression on these buildings in the instance map, yielding pseudo panoptic label GT. We futher define instance loss in fine-tuning stage to refine the instance geometry and enable more accurate panoptic label.
